Vix 是一门静态类型的编译型语言，用于构建简洁、可靠且高效的系统软件。

hello.vix
import string
import file
type Result:[T, E] = Ok(T) | Err(E)

fn loadName(path:string): Result:[string, string]
{

    let name =
        try file.read(path)
        |> string.trim
        |> string.uppercase

    return Ok(name)

}

fn main(): i32
{

    match loadName("user.txt")
    {

        Ok(name) →
            print("Hello", name)


        Err(e) →
            print("Error:", e)

    }

    return 0
}

01为什么选择 Vix?

01

编译即优化

基于 LLVM 后端，Vix 在编译期完成大量优化。没有沉重的运行时负担，生成的二进制文件精简高效，启动速度毫秒级。

02

模式匹配与 ADT

原生支持代数数据类型和强大的 match 表达式，让状态处理变得直观且穷尽。编译器会提醒你漏掉的每一种情况，而不是在运行时崩溃。

03

可控的底层能力

需要操作原始内存？Vix 提供指针运算和手动内存管理的能力。不需要时，现代化的语法和类型系统帮你远离段错误。
